Sin Auth (Public)
1 Autenticación (Registro o Login)
POST /api/auth

Ingresa credenciales para iniciar sesión o registrar un nuevo usuario en la plataforma Fintech. El JWT generado se almacenará en localStorage y se usará automáticamente en todas las llamadas subsiguientes.

2 Ingesta de Cartola o Transacción Manual
POST /api/transactions

Puedes subir una cartola bancaria (Excel, CSV o PDF) para clasificar transacciones automáticamente con la IA/NLP, o agregar transacciones manuales.

3 Consultar Transacciones y Feedback (Aprendizaje)
GET / PUT

Consulta las transacciones ingresadas. Si la IA o el clasificador cometió una imprecisión, corrige la categoría para alimentar el sistema de aprendizaje colaborativo.

Haz clic en "Cargar Mis Transacciones" para obtener la lista.

4 Generar Recomendaciones de Presupuesto (INE Chile)
POST /api/recommendations

Evalúa el patrón de gastos contra las referencias del Instituto Nacional de Estadísticas (INE Chile) y la regla 50/30/20.
