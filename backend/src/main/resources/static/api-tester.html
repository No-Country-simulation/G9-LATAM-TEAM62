Sin Auth (Public)
1 Autenticación (Registro o Login)
POST /api/auth

Ingresa credenciales para iniciar sesión o registrar un nuevo usuario en la plataforma Fintech. El JWT generado se almacenará en localStorage y se usará automáticamente en todas las llamadas subsiguientes.

2 Ingesta de Cartola o Transacción Manual
POST /api/transactions

Puedes subir una cartola bancaria (Excel, CSV o PDF) para clasificar transacciones automáticamente con la IA/NLP, o agregar transacciones manuales.

3 Consultar Transacciones, Filtros y Selección
GET / PUT

Consulta y filtra tus transacciones registradas. Puedes ordenar por categoría, monto o fecha, corregir categorías para el aprendizaje colaborativo y seleccionar qué transacciones enviar al Análisis Financiero.

0 seleccionadas Monto Seleccionado: $0

Haz clic en "Recargar BD" para obtener tus transacciones.

4 Generar Recomendaciones de Presupuesto (INE Chile)
POST /api/recommendations

Evalúa el patrón de gastos contra las referencias del Instituto Nacional de Estadísticas (INE Chile) y la regla 50/30/20.

5 Análisis Financiero y Diagnóstico Presupuestario
POST /api/analisis-financiero

Ejecuta el análisis financiero integral sobre las transacciones reales registradas en la base de datos (subidas vía cartola o manuales). Determina tu ratio de gasto, asigna tu perfil financiero y genera recomendaciones INE Chile.

Selecciona transacciones en el Paso 3 o marca "todas" para ejecutar el diagnóstico.
6 Auditoría e Historial de Recomendaciones y Perfiles
GET /api/users/...

Consulta el historial guardado en la base de datos de tus perfiles financieros y recomendaciones para verificar la auditoría del sistema.
